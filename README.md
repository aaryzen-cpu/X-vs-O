# X-vs-O

A command-line Tic-Tac-Toe game built with Python.

## Features

- Two-player gameplay
- Interactive board display
- Turn-based moves
- Win detection
- Simple terminal interface

## How to Run

```bash
python main.py
```

## Technologies Used

- Python 3

## Future Improvements

- Draw detection
- Move validation
- Single-player AI mode
- Graphical user interface (GUI)
